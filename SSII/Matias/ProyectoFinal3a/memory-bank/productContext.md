# Product Context — Autoescuela de Sistemas

## Visión del Producto
Autoescuela de Sistemas es una aplicación web interactiva diseñada para que los estudiantes de ciclos formativos de informática puedan preparar y practicar los contenidos de la asignatura de **Sistemas Informáticos** de forma amena y eficaz.

## ¿Por qué existe este producto?
Los estudiantes necesitan una herramienta de autoevaluación que les permita repasar de forma rápida conceptos clave antes de los exámenes. Actualmente no disponen de una plataforma específica que cubra las áreas de la asignatura: comandos Windows, comandos Linux, hardware, redes IP y contenedores.

## Público Objetivo
- Estudiantes de FP / Ciclos Formativos de Informática (DAW, DAM, ASIR)
- Cualquier persona interesada en aprender fundamentos de sistemas informáticos

## Funcionalidades Clave
1. **Tests por categoría**: el usuario elige una categoría y responde preguntas de opción múltiple.
2. **Feedback visual inmediato**: cada respuesta muestra si es correcta o incorrecta con animaciones.
3. **Puntuación final**: al terminar un test se muestra un resumen con aciertos, errores y porcentaje.
4. **Reintentar**: posibilidad de repetir el test de la misma u otra categoría.
5. **Diseño atractivo y responsive**: interfaz moderna con tema oscuro y efectos visuales.

## Categorías de Contenido
| Categoría | Descripción |
|---|---|
| Comandos Windows | CMD, PowerShell, gestión de archivos y red |
| Comandos Linux | Terminal, permisos, gestión de paquetes |
| Hardware | Componentes, arquitectura, periféricos |
| Redes IP | Direccionamiento, subnetting, protocolos |
| Contenedores | Docker, imágenes, volúmenes, redes |

## Experiencia de Usuario Deseada
El usuario abre la aplicación, ve una pantalla de bienvenida atractiva, elige una categoría, responde preguntas una a una con feedback inmediato, y al final obtiene su puntuación con opción de reintentar.
