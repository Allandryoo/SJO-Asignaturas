# Product Context - Autoescuela de Sistemas 3 AVA

## Visión del Proyecto

Crear una aplicación web de tests interactiva para una autoescuela especializada en aprender conceptos de hardware y sistemas informáticos. El objetivo es proporcionar una herramienta de aprendizaje efectiva para estudiantes que quieren dominar los fundamentos de sistemas: comandos de Windows, comandos de Linux, hardware, redes IP y contenedores.

## Propósito

- Facilitar el aprendizaje de conceptos técnicos de sistemas mediante tests de opción múltiple
- Proporcionar retroalimentación inmediata sobre el progreso del estudiante
- Crear una experiencia de aprendizaje atractiva y moderna

## Público Objetivo

- Estudiantes de formación profesional o universitaria en informatique
- Personas preparándose para certificaciones técnicas
- Cualquiera interesada en aprender sobre sistemas informáticos

## Funcionalidades Clave

- Tests de opción múltiple con 25+ preguntas
- 5 categorías: comandos Windows, comandos Linux, hardware, redes IP, contenedores
- Retroalimentación instantánea (aciertos/fallos)
- Interfaz moderna con tema oscuro y efectos visuales neón

## Valor Diferenciado

- Enfoque práctico y gamificado
- Diseño atractivo para motivar el aprendizaje
- Metodología profesional de desarrollo con Memory Bank
